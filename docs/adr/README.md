## 写法约定

每个 ADR 的文件头固定给出六项：**状态 / 日期 / 背景 / 决策 / 后果 / 依据**，
外加一段**一句话结论**（索引表里引用的就是它）。正文是原始推导——
搬过来时**不改判据、不改数字**，只把相对链接改成从本目录出发的路径。

新增 ADR 的顺序：新起一个编号、在此表加一行、并在 README 对应章节留摘要 + 链接。
编号只增不改（已发布的编号是引用锚点）。
